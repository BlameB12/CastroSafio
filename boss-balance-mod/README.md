# CastroSafio Boss Balance

NeoForge 1.21.1 endgame singleplayer balance mod.

Initial beta goals:
- Buff real bosses and minibosses without nerfing player equipment.
- Exclude Apotheosis Invaders/Elites (`apoth.boss`, `apoth.miniboss`).
- Resist hard crowd-control such as freeze, stun and paralysis.
- Block player-combat instant-execute deaths while allowing legitimate damage kills.
- Preserve shields as a skillful defensive answer.
- Add temporary healing pressure after dangerous boss hits.

Author: CastroSafio
